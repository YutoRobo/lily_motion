# v3.0.24 Legacy constraint evaluation

## Purpose

v3.0.24 evaluates the command trajectory generated by the vendored legacy state-machine emulator.
It does not change the legacy gait.  The goal is to identify where the reproduced legacy roll violates or approaches the main mechanical constraints.

Evaluated items:

- second joint absolute angle limit, default 95 deg
- ground penetration of knee and foot points, using vendored legacy FK
- approximate inter-leg proximity, using tibia-segment distances
- per-phase summaries and worst records

## Main command

Generate and evaluate in one step:

```bash
python archive/v3_experiment_scripts/run_v3_0_legacy_constraint_eval.py \
  --surface-id 1 \
  --move-dist 0.4 \
  --support-dist 0.7 \
  --max-step 30 \
  --initialize-step 100 \
  --second-joint-abs-max-deg 95 \
  --inter-leg-limit 0.04 \
  --output-command-log testdata/v3_0_24_legacy_commands.jsonl \
  --report-output testdata/v3_0_24_legacy_constraint_report.json
```

Evaluate an existing command log:

```bash
python archive/v3_experiment_scripts/run_v3_0_legacy_constraint_eval.py \
  --command-log testdata/v3_0_23_legacy_state_machine_commands.jsonl \
  --second-joint-abs-max-deg 95 \
  --inter-leg-limit 0.04 \
  --report-output testdata/v3_0_24_existing_constraint_report.json
```

Evaluate a Gazebo-preview-smoothed command log:

```bash
python archive/v3_experiment_scripts/run_v3_0_legacy_constraint_eval.py \
  --command-log testdata/v3_0_23_legacy_state_machine_commands.jsonl \
  --resample-factor 4 \
  --smooth-window 3 \
  --second-joint-abs-max-deg 95 \
  --inter-leg-limit 0.04 \
  --output-command-log testdata/v3_0_24_legacy_resampled_sw3.jsonl \
  --report-output testdata/v3_0_24_legacy_resampled_sw3_report.json
```

## Gazebo check

The evaluator can also write the command log for Gazebo replay.  After generating
`testdata/v3_0_24_legacy_resampled_sw3.jsonl`, replay with:

```bash
python tools/gazebo/run_v3_0_gazebo_replay.py \
  --rate 60 \
  --frame-hold-sec 0.0 \
  --hold-start-sec 2.0 \
  --hold-end-sec 3.0 \
  --command-log testdata/v3_0_24_legacy_resampled_sw3.jsonl \
  --verbose-publish
```

## Interpretation notes

- The second-joint metric is direct joint index 1 absolute angle.
- Ground clearance uses knee and foot positions from the vendored legacy FK and pitch-only body transform.
- The default ground tolerance is 1e-4 m to ignore numerical roundoff around exactly-zero contact.
- Inter-leg proximity is an approximate tibia-segment distance.  It is a diagnostic proxy, not a full Gazebo collision engine replacement.
- Use the phase summary first.  The worst frame lists are for targeted debugging.
